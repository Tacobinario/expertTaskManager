SuperExpertTaskManager
Tecnologías utilizadas
Flask: Framework principal para construir la aplicación web.
SQLAlchemy: Manejo eficiente de bases de datos.
HTML & CSS: Diseño y estructura de la interfaz.
SuperExpertTaskManager es una aplicación web diseñada para gestionar tareas de manera sencilla y eficiente. Permite agregar, visualizar, marcar como completadas y eliminar tareas desde una interfaz intuitiva. Ideal para usuarios que buscan mantenerse organizados y productivos. 💡

Características
✏ Agregar tareas: Captura títulos y descripciones para cada tarea.
✔ Marcar tareas como completadas: Actualiza el estado de las tareas realizadas.
🗑 Eliminar tareas: Borra las tareas que ya no son necesarias.
📋 Interfaz fácil de usar: Diseño limpio y centrado para una experiencia fluida.
